Provider Lookup demo

Try the provider-lookup Claude skill's workflow: find a U.S. healthcare provider and list every taxonomy code on their NPPES record, primary first.

Sample data. Browsers can't call the NPPES API directly (it doesn't allow cross-site requests), so this page searches a fixed set of real NPPES records, copied unchanged from the API. Records can change, so use the "View live record" link on a result to check it against NPPES. Claude calls the live API when it uses the skill.
